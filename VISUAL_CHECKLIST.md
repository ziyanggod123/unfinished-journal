# VISUAL_CHECKLIST

Use this checklist before approving any autonomous loop output.

## Global Rules

- [ ] No full-site visual redesign was attempted.
- [ ] No full-site dark mode was introduced.
- [ ] No changes were made to global typography.
- [ ] No changes were made to global palette or spacing scales.
- [ ] No changes were made to shared motion patterns.

## Protected Experience

- [ ] Submission flow visuals were left alone unless a human explicitly asked otherwise.
- [ ] Routing-related UI was not reworked.
- [ ] `localStorage`-dependent UI behavior was not altered.

## Star-Road Exception

- [ ] Only the star-road page is allowed to remain dark/starry.
- [ ] No other page inherited star-road dark styling.

## Loop Review

- [ ] The work stayed within docs, scripts, workflow, or other approved framework tasks.
- [ ] Any visual risk or uncertainty was documented in `LOOP_REPORT.md`.
