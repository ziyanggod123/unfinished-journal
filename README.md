# 未竟 — The Unfinished Journal

> 献给所有尚未完成，但不应被遗忘的思想。

**当前版本**：v0.9.0 | **线上预览**：https://5f5f65ce.unfinished-journal.pages.dev | **域名**：unfinishedjournal.com（Initializing）

## 项目定位

未竟是一个面向未完成思想、失败实验、早期构想和跨学科假说的学术与创新平台。它不属于传统期刊——不追求"已发表"的终点，而是为那些处于中间状态的研究提供一个被看见、被保护、被协作的空间。

### 核心价值

- **记录**：为未完成的工作提供不可篡改的时间戳
- **保护**：在正式发表前保护思想的优先权
- **协作**：连接需要帮助的项目和愿意贡献的研究者
- **孵化**：让有价值但尚未成形的想法获得延续的可能

## 快速开始

### 本地运行

```bash
# 方式一：直接用浏览器打开
start index.html

# 方式二：使用任意 HTTP 服务器
npx serve .
# 或
python -m http.server 8000
```

然后在浏览器中访问 `http://localhost:8000`。

## 技术栈

- **前端**：纯 HTML5 + CSS3 + Vanilla JavaScript（零依赖）
- **路由**：基于 hash 的 SPA 路由
- **数据**：localStorage 模拟数据库（预留 Supabase / Firebase / Airtable 接口）
- **字体**：思源宋体 Noto Serif SC + Inter（Google Fonts CDN）
- **动画**：Intersection Observer API（滚动淡入）
- **图标**：纯 CSS / Unicode 字符，无图标库依赖

## 设计理念

"灰色纪念碑上的金色裂缝"——灰色代表未竟的中间状态，金色裂缝代表其中蕴含的潜在价值。
